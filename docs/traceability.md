## Design patterns

Stage 2 needs at least five distinct patterns, evident in the code.

| Pattern | Stage 1 participants | Status | Implemented files |
|---|---|---|---|
| Facade | FindAnythingService (facade); GuiController, CliApp (clients) | Implemented | `core/FindAnythingService.java`; clients `ui/CliApp.java` (waits on each future with `join()`) and `ui/GuiController.java` (handles each future on the JavaFX thread) |
| Observer | Indexer (subject), IndexStatusListener (observer), GuiController (concrete observer), IndexStatus | Implemented | `indexing/Indexer.java` (`addStatusListener()`, `notifyStatus()`), `indexing/IndexStatusListener.java`, `indexing/IndexStatus.java`, `ui/GuiController.java` (`onStatusChanged()`: the concrete observer, registered through `FindAnythingService.addStatusListener()`), `ui/MainWindow.java` (`showStatus()`) |
| Command | Tool (command), SearchTool, ReadExcerptTool, CompareTool, ToolRegistry (invoker), AgentController (client) | Implemented (`CompareTool` comes with F10, Tier 2) | `agent/AgentController.java` (client: `run()` passes each `ToolCall` to the invoker), `agent/Tool.java` (`getSpec()`, `validate()`, `execute()`), `agent/ToolRegistry.java` (`execute()`, `getCallLog()`), `agent/SearchTool.java` (receiver `search/SearchEngine.java`), `agent/ReadExcerptTool.java` (receiver `storage/SearchIndex.java`), `agent/ToolResult.java` |
| Adapter | LlmClient, TextExtractor, EmbeddingModel (targets); LangChain4jClient, IsolatedTextExtractor, LocalEmbeddingModel (adapters) | Implemented (LocalEmbeddingModel only with F05) | `llm/LlmClient.java` (target: `LlmRequest`, `LlmResponse`, `Message`, `ToolSpec`, `ToolCall`), `llm/LangChain4jClient.java` (adapter: LangChain4j's `OpenAiChatModel` and `OllamaChatModel` stay inside); `indexing/TextExtractor.java`, `indexing/IsolatedTextExtractor.java` (Tika stays inside); `storage/SearchIndex.java` keeps Lucene inside the same way |
| Decorator | LlmClientDecorator, RedactingLlmClient, LoggingLlmClient around LangChain4jClient | Implemented | `llm/LlmClient.java` (component), `llm/LangChain4jClient.java` (concrete component), `llm/LlmClientDecorator.java` (abstract decorator: holds `wrappedClient` and delegates), `llm/RedactingLlmClient.java` (`complete()`: withholds local-only messages, redacts the rest), `llm/LoggingLlmClient.java` (`complete()`: appends to the privacy log, then delegates); the chain is built in `llm/LlmClientFactory.java` (`createClient()`) for cloud models only |
| Factory | LlmClientFactory | Implemented (one cached client per `ModelSettings`: the decorated chain for a cloud model, the plain adapter for a local one) | `llm/LlmClientFactory.java` (`createClient()`, `build()`); client `core/FindAnythingService.java` (`testBackend()`, and `ask()` with the conversation's own settings) |
| MVC | Views, GuiController, FindAnythingService | Implemented (SettingsDialog comes with the settings commit) | Views `ui/MainWindow.java`, `ui/ResultsView.java`, `ui/DetailPane.java` (display only; they report the user's actions through callbacks and never call the model); controller `ui/GuiController.java`; model `core/FindAnythingService.java` and the domain behind it, shared with `ui/CliApp.java` |
